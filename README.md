# Patlak-vs.-neuronales-Netz-Ki-aus-verrauschten-FDG-Kurven
Du baust eine kleine, reproduzierbare Pipeline: FDG-Zeit-Aktivitäts-Kurven (TACs) mit einem 2-Gewebe-Kompartimentmodell simulieren, Ki per Patlak-Regression schätzen und ein neuronales Netz trainieren, das Ki direkt aus verrauschten Kurven vorhersagt. Am Ende vergleich beider Methoden je Rauschniveau.
